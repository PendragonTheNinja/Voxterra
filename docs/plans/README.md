# Plans

Work that has been thought through and not yet chosen.

- `engineering-backlog.md` — the work packages from the November 2026 code
  audit (`docs/notes/code-audit-2026-11.md`): what to do, in what order,
  how to measure it and how to know it is done. Start here.
- `ci-workflow.yml` — a proposed GitHub Actions workflow (package T1).

Like `docs/vision.md`, these are proposals. A package is built when the
owner picks it; the larger ones become milestone specs and ADRs first
(CLAUDE.md, *Workflow rules*). `docs/vision.md` says what the game should
become; this folder says what the engine under it needs.
